# Habit Tracker

A simple desktop application built using **Node.js and Electron** that helps users create and track their daily habits.

The purpose of this project is to help users build good habits and maintain a productive daily routine.

## Features

- **Add Habits:** Add new daily habits to your list.
- **Complete Habits:** Mark habits as completed.
- **Delete Habits:** Remove habits you no longer need.
- **Daily Progress:** View how many habits you have completed today.
- **Save Habits:** Habits are saved locally using LocalStorage, so they remain available after closing the application.

## How to Use

1. Open the Habit Tracker application.
2. Enter a habit name in the input field.
3. Click the **Add Habit** button.
4. Click **Complete** when you finish a habit.
5. Click **Delete** to remove a habit.
6. Check your daily progress in the progress section.
